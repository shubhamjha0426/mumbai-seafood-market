# Mumbai Seafood Market — Front-end Demo

A responsive, premium-style demo website for a Digital Seafood Marketplace in Mumbai City.

## Features
- Responsive home page and seafood product cards
- Product search
- Category filters (Fish, Shellfish, Coastal Specials)
- Add to basket, change quantity, remove items
- Basket saved in the browser using localStorage
- Vendor interest form (front-end demo only)
- Mobile navigation and demo checkout modal

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or install the Live Server extension in VS Code and click **Go Live**.
3. Internet is needed for Google Fonts and product photos.

## Publish for free with GitHub Pages
1. Sign in to https://github.com/
2. Create a **Public** repository, for example `mumbai-seafood-market`.
3. Upload `index.html` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then Save.
7. Wait a few minutes and open the URL shown in the Pages section. It is usually:
   `https://YOUR-USERNAME.github.io/mumbai-seafood-market/`

Official guide: https://docs.github.com/en/pages/quickstart

## Important limitations
This is a front-end student-project demo. Product prices and listings are sample data. The basket is stored only in the current browser. Vendor form submissions are not sent to a server. No real ordering, delivery coordination, authentication, database, or payment processing is connected.
